How to use FraudWatch

Inspect individual records or upload a CSV containing the model's 30 required features for batch analysis.

Dataset note: Demo records are samples from a public anonymized credit-card dataset. Demo IDs are labels for this project, not real bank transaction IDs.
Model note: Model probabilities are estimates, not guarantees. This project is for demonstration and evaluation, not live financial decisions.

Inspect a transaction

Select a record from the active dataset.
Actual dataset labels are shown only when the uploaded CSV includes a Class column. Real transactions normally have no known label at prediction time.

CSV analysis

Required columns: Time, V1–V28, Amount.
Optional columns: Demo_Transaction_ID (or Transaction ID) and Class (0 = legitimate, 1 = fraud). Maximum 500 rows.
