How to use FraudWatch

Inspect a transaction to review a demo record by ID, or upload a CSV containing the model's 30 required features for batch analysis.

Dataset note: The bundled demo records are sampled from a public anonymized credit-card dataset. The demo IDs are labels for this project, not real bank transaction IDs or Indian bank records.
Model note: The probability is the model's estimate, not a guarantee. This project is for demonstration and evaluation, not live financial decisions.

Inspect a transaction

Select a record from the bundled demo sample and inspect the model result.
The actual label is shown only because this bundled dataset is an evaluation sample with known labels. In a real screening workflow, actual labels would not be known at prediction time.

CSV analysis

Upload transactions for batch predictions. Required columns: Time, V1–V28, Amount.
Optional columns: Demo_Transaction_ID (or Transaction ID) and Class (0 = legitimate, 1 = fraud). Max 500 rows per upload.
